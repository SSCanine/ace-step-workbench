ACE-Step Workbench guide

Everything you need, in the order you need it. Hover any i in the app for a short explanation of that control.

1. Quick start

  1. Install once. Run install.bat (Windows) or ./install.sh (Linux). It downloads ACE-Step 1.5 next to this app and sets everything up. Models (about 10 GB for the default set) download the first time you generate.
  2. Start. Run start.bat / ./start.sh. Your browser opens the Workbench. The dot at the bottom left turns green when ACE-Step has loaded (first start takes a few minutes).
  3. Write. Open Write, type an idea ("a sad synthwave song about a robot's last night"), press Write song. No AI writer set up yet? You still get a rule-based draft; see section 4 to plug one in.
  4. Create. Press Send to Create, then Generate. A 3-minute song takes roughly 10-60 seconds on a modern NVIDIA GPU.
  5. Refine. Love the melody but one word sounds wrong? Open the song in Studio, fix the line, and re-sing just that part with the same seed (section 10).
Need: an NVIDIA GPU with 8 GB+ VRAM (12 GB+ recommended, 16 GB+ for LoRA training at comfortable speed), about 20 GB free disk, Windows 10/11 or Linux. Apple Silicon works through ACE-Step's MPS support but is slower.

3. Writing songs with AI

The Write tab turns an idea into a complete, ready-to-generate song. Fill in as much or as little as you like: genre, mood, vocals, language, length. Then:

  • Write song writes everything from scratch.
  • Surprise me invents an idea for you.
  • Revise applies an instruction to the current song ("make the chorus shorter", "more hopeful bridge", "switch to Spanish").
  • Convert moves a song between ACE-Step and Suno format.
  • Send to Create fills the generator with the result.

Every field stays editable. The AI is a co-writer, not the boss.

5. Suno mode vs ACE-Step mode

ACE-Step modeSuno mode
FilteringNone. Explicit lyrics, real references, anything.Rephrased so Suno accepts it.
FieldsCaption, lyrics, BPM, key, time signature, length, languageStyle (max 1000 chars), Exclude, Title, Lyrics (max 5000 chars)
Section tags[Chorus - anthemic][Chorus: anthemic]
Artist namesAllowed (though ACE-Step barely knows artists: describe the sound)Removed and replaced with sound descriptions
Where it goesStraight into CreateCopy buttons + "Open Suno" (paste into Suno's Custom/Advanced mode)

Suno mode runs two passes: the AI writer follows Suno's rules, then a local safety net strips "in the style of X" / "X type beat" phrases, removes names on your blocklist, converts tags, trims to Suno's limits and (optionally) softens words Suno's lyric filter tends to flag. Every change is listed under the result so nothing changes silently. Edit the lists in data/suno_blocklist.txt and data/suno_soften.json.

6. Captions that work

The caption is the single most important input. Combine several dimensions:

DimensionExamples
Genremelodic techno, indie folk, boom bap, cinematic orchestral, synthwave
Moodmelancholic, euphoric, brooding, intimate, triumphant
Instrumentsfingerpicked acoustic guitar, 808 bass, supersaw leads, string section
Texturewarm, crisp, airy, punchy, lush, gritty, lo-fi
Vocalsbreathy female vocal, raspy male vocal, choir, falsetto, rap
Era / production80s gated drums, 90s grunge, modern radio-ready mix, live room recording
  • Specific beats vague: "sad piano ballad with breathy female vocal" > "sad song".
  • Don't put BPM or key in the caption; use their own fields.
  • Conflicting styles confuse the model. Want a change? Describe it as a journey: "starts as soft piano, explodes into metal".
  • Repeat what you want more of.
  • Artist names do little in ACE-Step: describe what makes that artist sound like that.

7. Lyrics and section tags

Lyrics are the song's timeline. Put each tag on its own line and leave a blank line between sections.

[Intro]

[Verse 1]
Streetlights hum a song I used to know
Every window paints a softer glow

[Chorus - anthemic]
WE RUN until the morning (morning)
Hearts on fire, never falling

[Guitar Solo]

[Bridge - whispered]
Hold the line... hold the line

[Outro]
KindTags
Structure[Intro] [Verse 1] [Pre-Chorus] [Chorus] [Bridge] [Outro]
Energy[Build] [Drop] [Breakdown] [high energy] [low energy] [explosive]
Instrumental[Instrumental] [Guitar Solo] [Piano Interlude] [Drum Break] [Fade Out]
Voice[whispered] [falsetto] [raspy vocal] [powerful belting] [spoken word] [harmonies] [ad-lib] [call and response]
  • 6-10 syllables per line; matching lines should have similar counts.
  • Keep tag modifiers short: [Chorus - anthemic], not five adjectives.
  • Make caption and tags agree: a [Guitar Solo] needs guitar in the caption.
  • Want an instrumental? Write just [Instrumental] or tick "Instrumental".

10. Studio: same seed, fix a phrase

Every song stores its exact seed and settings. In Studio you can:

  1. Regenerate (same seed). Same seed + same settings = a very similar song. Change a few words in the lyrics first and you get the same musical idea with your new words. Bigger lyric changes drift further, because the lyrics are part of what the model listens to.
  2. Re-sing a section (repaint). Drag across the waveform to select a few seconds (or pick a lyric line and press Select line's time for an estimate), edit the words for that part, press Re-sing selection. Only that span is regenerated; the rest of the song stays exactly as it was. Best for fixing one word or phrase.
  3. Variations. Keep everything and change only the seed for a fresh take on the same song.
Tip: when a single word is mispronounced, combine both tools: respell the word (section 8), then re-sing only that line's few seconds.

11. Training a LoRA

A LoRA is a small file (tens of MB) that teaches ACE-Step a sound: a genre, a production style, a vocal character. You train it from your own tracks.

  1. Collect 8-30 songs that share the sound you want. Use music you own or have the rights to. Full-length, good-quality files (WAV/FLAC/MP3 320).
  2. Train tab → New dataset. Name it, add the files. Pick a trigger word: a made-up token like zxsynth that you'll put in captions later.
  3. Describe each track. Press Auto-label to have ACE-Step estimate BPM, key and a caption for every file; fix anything wrong. Add lyrics for vocal tracks (or mark them instrumental). Better labels = better LoRA.
  4. Preprocess. Converts audio to training tensors (a few minutes).
  5. Train. Start with the Balanced preset. Watch the loss chart: it should drop then flatten. Checkpoints are saved along the way.
  6. Use it. In Create, pick the LoRA, set strength 0.6-1.0, and start your caption with the trigger word.
Training uses the GPU heavily. Close games and other AI apps first. The Workbench stops generation while training.

12. Troubleshooting

SymptomFix
Status dot stays yellow for a long timeFirst start downloads models (several GB). Watch Settings → ACE-Step → Server log.
CUDA out of memoryClose other GPU apps (games, image generators, local LLMs). In Settings pick the smaller LM (0.6B) or turn on "Offload LM to CPU", or disable the LM.
The AI writer says "could not reach"Its server isn't running (start Ollama / LM Studio), or the URL is wrong. Press Test in Settings.
The AI writer refusesHosted models have policies. Switch to a local uncensored model.
Garbled or mumbled vocalsShorter lines, clearer section tags, fewer stacked tags; fix words in Studio. LoRAs at strength above 1.0 often hurt vocals.
Song is cut off or rushedRaise Duration; slower BPMs need more time for the same lyrics.
Port already in useChange it in start.bat (--port) or Settings → ACE-Step API URL.

13. Glossary

DiTThe diffusion model that actually makes the audio. "turbo" = fast (8 steps), "base" = slower, more controllable, the usual LoRA training target.
LMA small language model that plans the song (fills in BPM, key, structure codes) before the DiT renders it. "Thinking" mode uses it more.
SeedThe random starting point. Same seed + same settings = same song.
CFG / guidanceHow strictly the model follows your caption. Higher = more literal, sometimes harsher.
RepaintRegenerate only a time span of an existing song.
LoRA / LoKrSmall add-on weights that teach a style. LoKr is a lighter, faster-training variant.
Trigger wordA made-up word you train into a LoRA and put in captions to switch the style on.
